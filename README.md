# NLP Job Description Skill Extraction

An NLP-based application that extracts technical skills from job descriptions using multiple Natural Language Processing and Machine Learning techniques. The project also normalizes extracted skills, maps them to categories, recommends related technologies, and provides a web-based interface for users.

---

## 📌 Project Overview

Job descriptions often contain a large amount of information, making it difficult to quickly identify the technical skills and technologies required for a particular role.

This project focuses on automatically extracting and analyzing skills from job descriptions using NLP techniques.

The project was developed as a step-by-step NLP pipeline, starting from data preprocessing and rule-based extraction and progressing to semantic similarity, Named Entity Recognition, Machine Learning, Transformer-based extraction, skill normalization, and finally a web application.
